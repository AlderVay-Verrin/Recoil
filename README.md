# Recoil Zero-G

A single-page, browser-native zero-gravity arena game.

## Run

```bash
npm install
npm run dev
```

Open the displayed local URL in Chrome. Click a mode, then click the game to capture the mouse.

## Controls

- WASD: thrust
- Mouse: aim
- Space/C: vertical thrust
- Q/E: roll
- Shift: dash
- F: mag-lock onto nearby debris
- V: kinetic pulse
- Left mouse: fire
- Right mouse: stabilize aim
- R: reload
- 1–6: switch weapon
- Tab/Escape: pause or release mouse
